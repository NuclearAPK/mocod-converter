# Как внести изменения

Откройте issue с версией Python, системой и шагами воспроизведения. Для примеров используйте вымышленные данные. Реестры клиентов и протоколы МоКоД могут содержать персональные данные, поэтому их следует хранить вне GitHub.

Перед pull request запустите `python -m unittest discover -s tests -v`. Для изменений формата выгрузки укажите версию формы или конфигурации, которую вы проверили, и добавьте тест с синтетическими данными.
