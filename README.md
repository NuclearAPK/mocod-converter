# МоКоД Конвертер

Локальное приложение и команда для преобразования реестра займов МФО из Excel в CSV для проверки в МоКоД. Поддерживается форма на 120 граф со II квартала 2026 года и конфигурация `RZMFO_PL (15.06.2026).cfg`. Приложение работает на Windows, macOS и Linux с Python 3.10 или новее.

## Установка

```sh
git clone https://github.com/NuclearAPK/mocod-converter.git
cd mocod-converter
python -m pip install .
```

На macOS и Linux вместо `python` может использоваться `python3`. Если пакетный менеджер системы требует виртуальное окружение, создайте его командой `python -m venv .venv` и запустите установку интерпретатором из него.

## Использование

**С окном.** Запустите `mocod-converter`, выберите XLSX и нажмите «Сохранить CSV». Для окна нужен Tk. Его наличие можно проверить командой `python -m tkinter`. В Debian и Ubuntu Tk обычно устанавливается пакетом `python3-tk`.

**Из терминала.**

```sh
python -m mocod_converter "Реестр.xlsx" "Реестр_МоКоД.csv"
```

Чтобы заменить существующий CSV, добавьте `--force`. Конвертер читает сохранённые результаты формул. При ошибке в формуле или отсутствии сохранённого результата сообщение укажет строку и поле.

## Формат и проверка

CSV содержит заголовки `F1`–`F120`, разделитель `;`, окончания строк CRLF и кодировку Windows-1251. Даты записываются в формате `ГГГГ-ММ-ДД`, десятичные числа — с запятой, заполненные текстовые поля — в двойных кавычках. В выгрузке `Да` в `F16` приводится к `да`, а отметка `не рассчитывался` в `F76`–`F80` выгружается пустой, как её интерпретирует МоКоД. Исходный XLSX остаётся без изменений.

Для проверки добавьте CSV в набор данных «Реестр займов МФО» в режиме «РЗМФО» и запустите логический контроль. В конфигурации укажите фактическую дату формирования реестра и даты окончания месяцев нужного квартала. Обработка выполняется локально. Логические проверки реестра выполняет МоКоД.
